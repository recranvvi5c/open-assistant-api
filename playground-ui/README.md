# 项目概述


## 项目运行

1. 本地启动
```bash
$ yarn install
$ yarn start
```

打开浏览器访问 `http://localhost:8000`

## Local development

```bash
npm install
npm run dev
```

The UI reads the API base URL from its environment config; point it at `http://localhost:8086/api`
when running the API locally.
